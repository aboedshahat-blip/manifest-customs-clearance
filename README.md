# المصري الدولي للتخليص الجمركي ونقل البضائع
## منظومة تفريغ وتحويل منافيست السيارات الجمركي (PDF to Word & Excel)

منظومة ويب متطورة مخصصة لمكتب **المصري الدولي للتخليص الجمركي** (إدارة: أ / محمد حسن مرزوق - ت: +20 12 21356668) لتحويل وتفريغ شيتات منافيست السيارات الجمركية (صادر، ترانزيت، تربتيك، مبادرة، متخلف) من ملفات **PDF** مباشرة إلى كشوف وجداول رسمية بصيغ **Word (.docx)** و **Excel (.xlsx)** و **CSV** بنفس ترتيب وأعمدة النموذج المعتمد بدقة 100%.

---

## 🌟 مميزات المنظومة

1. **التعرف التلقائي الذكي على أنماط المنافيست (Universal Auto-Detection)**:
   - **نمط الجداول الممتدة (Tabular Grid)**: مثل منافيست شركة الطاقة البحرية (Sea Power) وتفريغ كافة الصفحات والأعمدة واستخراج رقم الـ ACID التابع لكل مستلم بدقة.
   - **نمط كروت البوالص المستقلة (Card/Box Style)**: مثل منافيست شركة بحور المشرق (OSLCO) لمنافيست الصادر والترانزيت والمتخلف.
   - **معالجة البوالص متعددة المركبات**: ربط الشاسيهات المتعددة داخل نفس البوليصة ببيانات الشاحن والمستلم ورقم ACID.

2. **الجدول الموحد المعتمد (6 أعمدة)**:
   - `مسلسل`
   - `رقم البوليصة`
   - `اسم الشاحن`
   - `رقم الـ acid`
   - `نوع البضاعة`
   - `رقم الشاسيه`

3. **تصدير رسمي مباشر**:
   - **Word (.docx)**: ترويسة رسمية باسم "المصري الدولي للتخليص الجمركي" مع جدول منسق متوافق تماماً مع Microsoft Word.
   - **Excel (.xlsx)**: شيت إكسيل منسق من اليمين لليسار RTL.
   - **CSV**: متوافق مع كافة البرامج.
   - **نسخ فوري للجدول**: للصق المباشر في أي مستند.

4. **جاهز للنشر على Vercel و Node.js**:
   - مهيأ عبر `vercel.json` و `api/index.js` للعمل كـ Serverless Application على منصة Vercel.
